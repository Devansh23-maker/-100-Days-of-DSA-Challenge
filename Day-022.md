---

✅ Problems Solved

1. Binary Search

Platform: LeetCode (LC 704)

Approach:

- Applied the standard binary search algorithm on a sorted array.

Time Complexity: O(log n)

Space Complexity: O(1)

---

2. Search Insert Position

Platform: LeetCode (LC 35)

Approach:

- Used binary search to find the target or its correct insertion index.

Time Complexity: O(log n)

Space Complexity: O(1)

---

3. First Bad Version (or First & Last Position if you solved LC 34)

Approach:

- Performed binary search while shrinking the search space toward the first valid answer.

Time Complexity: O(log n)

Space Complexity: O(1)

---

4. Find Peak Element

Platform: LeetCode (LC 162)

Approach:

- Compared the middle element with its neighbor.
- Moved toward the side that must contain a peak.

Time Complexity: O(log n)

Space Complexity: O(1)

---

🧠 Key Learnings

- Binary Search works whenever the search space is monotonic.
- Always define the search range carefully and update "low" and "high" correctly.
- Many optimization problems use Binary Search on Answers instead of directly searching an array.
- Handling edge cases correctly is crucial to avoid infinite loops.
