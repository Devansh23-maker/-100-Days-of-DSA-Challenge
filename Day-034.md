🧠 Basic Node Structure
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

🧠 Key Learnings
A Linked List consists of nodes connected using references.
The first node is called the head.
The last node points to None.
Unlike arrays, Linked Lists don't require contiguous memory.
Insertion/deletion can be efficient when you already have the required node/reference.
Traversal generally takes O(n).
