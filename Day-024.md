## ✅ Problems Solved

### 1. Search a 2D Matrix

**Platform:** LeetCode (LC 74)

**Approach:**

* Treated the matrix as a flattened sorted array.
* Applied Binary Search by converting the middle index into row and column indices.

**Time Complexity:** O(log(m × n))

**Space Complexity:** O(1)

---

### 2. Search a 2D Matrix II

**Platform:** LeetCode (LC 240)

**Approach:**

* Started from the top-right corner.
* Eliminated one row or one column in every step based on comparisons.

**Time Complexity:** O(m + n)

**Space Complexity:** O(1)

---

### 3. Find Peak Element II

**Platform:** LeetCode (LC 1901)

**Approach:**

* Applied Binary Search on columns.
* Found the maximum element in the current column and moved toward the larger neighboring column.

**Time Complexity:** O(m log n)

**Space Complexity:** O(1)

---

## 🧠 Key Learnings

* Binary Search is applicable to matrices in multiple ways depending on the matrix properties.
* Flattening the matrix works only when the entire matrix is globally sorted.
* The staircase search is optimal for row-wise and column-wise sorted matrices.
* Peak-finding problems use Binary Search on dimensions rather than values.
