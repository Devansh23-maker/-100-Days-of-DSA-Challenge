✅ Problems Solved

1. Find Minimum in Rotated Sorted Array

Platform: LeetCode (LC 153)

Approach:

- Compared the middle element with the rightmost element.
- Narrowed the search space toward the pivot (minimum element).

Time Complexity: O(log n)

Space Complexity: O(1)

---

2. Search in Rotated Sorted Array

Platform: LeetCode (LC 33)

Approach:

- Determined which half of the array was sorted.
- Continued binary search only in the valid sorted half.

Time Complexity: O(log n)

Space Complexity: O(1)

---

3. Kth Element of Two Sorted Arrays

Platform: GeeksforGeeks

Approach:

- Applied Binary Search on the smaller array.
- Partitioned both arrays so that exactly k elements were on the left side.

Time Complexity: O(log(min(n, m)))

Space Complexity: O(1)

---

4. Search a 2D Matrix

Platform: LeetCode (LC 74)

Approach:

- Treated the matrix as a single sorted array.
- Converted the 1D index into row and column indices during binary search.

Time Complexity: O(log(m × n))

Space Complexity: O(1)

---

🧠 Key Learnings

- Rotated array problems rely on identifying the sorted half in every iteration.
- Binary Search can be applied to matrices by flattening the index space.
- Partition-based Binary Search is an important interview pattern for two sorted arrays.
- Correctly handling boundary conditions is essential in advanced Binary Search problems.
