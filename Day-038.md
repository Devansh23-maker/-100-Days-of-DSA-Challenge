✅ Problems Solved
1. Sort List
Platform: LeetCode — LC 148
Approach:
Used Merge Sort because Linked Lists can be efficiently split and merged without random access.
Find the middle using slow/fast pointers.
Recursively sort both halves.
Merge the two sorted halves.
Time Complexity: O(n log n)
Space Complexity: O(log n) (recursive stack)
2. Remove Nth Node From End of List
Platform: LeetCode — LC 19
Approach:
Used two pointers with a gap of n nodes.
Move fast ahead by n positions.
Move both pointers together until fast reaches the end.
Remove the node after slow.
Time Complexity: O(n)
Space Complexity: O(1)
🧠 Key Learnings
Merge Sort is one of the best sorting techniques for Linked Lists.
Fast & Slow pointers help find the middle efficiently.
Two pointers can find the nth node from the end in a single traversal.
A dummy node makes deletion problems easier, especially when removing the head.
