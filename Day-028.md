## ✅ Problems Solved

### 1. Aggressive Cows

**Platform:** GeeksforGeeks

**Approach:**

* Sorted the stall positions.
* Binary searched the maximum minimum distance between cows.
* Used a greedy feasibility check to determine if all cows could be placed.

**Time Complexity:** O(n log n + n log D)

**Space Complexity:** O(1)

---

### 2. Kth Missing Positive Number

**Platform:** LeetCode (LC 1539)

**Approach:**

* Applied Binary Search on the sorted array.
* Calculated the number of missing integers before each index using:
  `missing = arr[mid] - (mid + 1)`
* Narrowed the search until locating the kth missing number.

**Time Complexity:** O(log n)

**Space Complexity:** O(1)

---

## 🧠 Key Learnings

* Binary Search can optimize problems even when the target value is not explicitly present.
* A greedy feasibility function is essential for Binary Search on Answer problems.
* Counting missing elements mathematically avoids linear scanning.
* Always identify whether the search is on indices, values, or the answer space.
