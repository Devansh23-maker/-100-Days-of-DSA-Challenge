📚 Doubly Linked List Revision
1. Reverse a Doubly Linked List

Pattern: Pointer Manipulation

Swap prev and next for every node.
Update the head after traversal.

Time: O(n)
Space: O(1)

2. Delete Head of Doubly Linked List

Pattern: Deletion

Move head to head.next.
Set the new head's prev to None.

Time: O(1)
Space: O(1)

3. Delete Last Node

Pattern: Tail Manipulation

Traverse to the last node.
Update the previous node's next to None.

Time: O(n)
Space: O(1)

4. Remove Duplicates from Sorted DLL

Pattern: Pointer Manipulation

Traverse the list.
Remove consecutive duplicate nodes.
Correctly update both prev and next.

Time: O(n)
Space: O(1)

🗄️ SQL Practice
5. Order by Database Query

Concept: ORDER BY

Practice finding records based on an ordering condition such as:

SELECT *
FROM Employees
ORDER BY salary DESC;
Key Learning
ORDER BY column_name ASC;

→ Lowest to highest / alphabetical order

ORDER BY column_name DESC;

→ Highest to lowest / reverse alphabetical order

You can also combine it with LIMIT:

SELECT *
FROM Employees
ORDER BY salary DESC
LIMIT 5;

This returns the top 5 highest salaries.

🧠 Key Takeaways
DLL operations require careful handling of both prev and next.
Always consider special cases: empty list, one node, head, and tail.
ORDER BY is fundamental for SQL sorting and ranking questions.
LIMIT becomes especially useful when combined with ORDER BY.
