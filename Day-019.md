## ✅ Problems Solved

### 1. Largest Subarray with Sum 0

**Platform:** GeeksforGeeks

**Approach:**

* Used a HashMap to store the first occurrence of every prefix sum.
* Whenever the same prefix sum appeared again, calculated the maximum subarray length.

**Time Complexity:** O(n)

**Space Complexity:** O(n)

---

### 2. Count Subarrays with Given XOR K

**Platform:** GeeksforGeeks

**Approach:**

* Maintained prefix XOR values.
* Used a HashMap to count previous XOR values satisfying the required condition.

**Time Complexity:** O(n)

**Space Complexity:** O(n)

---

### 3. Merge Overlapping Intervals

**Platform:** LeetCode (LC 56)

**Approach:**

* Sorted intervals based on starting points.
* Merged overlapping intervals while traversing once.

**Time Complexity:** O(n log n)

**Space Complexity:** O(n)

---

### 4. Merge Two Sorted Arrays Without Extra Space

**Platform:** GeeksforGeeks

**Approach:**

* Used the **Gap Method (Shell Sort Technique)**.
* Compared elements with a shrinking gap until the gap became 1, achieving in-place merging without additional memory.

**Time Complexity:** O((n + m) log(n + m))

**Space Complexity:** O(1)

---

## 🧠 Key Learnings

* Prefix Sum and XOR are powerful techniques for subarray problems.
* HashMaps help optimize brute-force solutions from **O(n²)** to **O(n)**.
* Sorting is essential for interval merging problems.
* The Gap Method is a classic interview technique for merging sorted arrays in-place without extra space.
