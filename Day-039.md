✅ Problems Solved
1. Add Two Numbers

Platform: LeetCode — LC 2

Approach:

Traverse both linked lists simultaneously.
Add corresponding digits along with the carry.
Create a new node for each resulting digit.
Continue until both lists and the carry are exhausted.

Time Complexity: O(max(n, m))
Space Complexity: O(max(n, m))

2. Sort a Linked List of 0s, 1s and 2s

Platform: GeeksforGeeks

Approach:

Count the number of 0, 1, and 2 nodes.
Traverse the linked list again and replace node values according to their counts.

Time Complexity: O(n)
Space Complexity: O(1)

Alternative: This can also be solved by maintaining separate linked lists for 0, 1, and 2 and then connecting them.

🧠 Key Learnings
A dummy node makes Linked List construction much easier.
Always remember to handle the carry when adding numbers.
Linked Lists can be rearranged without creating new nodes by changing next pointers.
For problems containing only a few possible values like 0, 1, 2, frequency counting can give a simple O(n) solution.
