✅ Problems Solved

1. Valid Palindrome

Platform: LeetCode (LC 125)

Approach:

- Used two pointers from both ends.
- Ignored non-alphanumeric characters and compared characters case-insensitively.

Time Complexity: O(n)

Space Complexity: O(1)

---

2. Longest Common Prefix

Platform: LeetCode (LC 14)

Approach:

- Compared characters column by column across all strings.
- Stopped when a mismatch was found.

Time Complexity: O(n × m)

Space Complexity: O(1)

---

3. Valid Anagram

Platform: LeetCode (LC 242)

Approach:

- Counted character frequencies using an array/hash map.
- Compared the frequency counts of both strings.

Time Complexity: O(n)

Space Complexity: O(1)

---

4. Reverse String

Platform: LeetCode (LC 344)

Approach:

- Used two pointers to swap characters from both ends until they met.

Time Complexity: O(n)

Space Complexity: O(1)

---

🧠 Key Learnings

- Two Pointers simplify many string problems.
- Character frequency counting is a common interview technique.
- Always consider edge cases like empty strings, spaces, and case sensitivity.
- Simple string problems help build a foundation for advanced sliding window and hashing problems.
