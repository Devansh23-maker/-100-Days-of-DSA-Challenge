✅ Problems Solved

1. Sum of Beauty of All Substrings

Platform: LeetCode (LC 1781)

Approach:

For every starting position, maintained character frequencies while extending the substring.

Calculated max_frequency - min_frequency for each substring.


Time Complexity: O(n²)

Space Complexity: O(1)


---

2. Longest Palindromic Substring

Platform: LeetCode (LC 5)

Approach:

Used Expand Around Center.

Considered both odd-length and even-length palindromes.


Time Complexity: O(n²)

Space Complexity: O(1)


---

3. Maximum Nesting Depth of the Parentheses

Platform: LeetCode (LC 1614)

Approach:

Increased the current depth when encountering (.

Decreased it when encountering ).

Kept track of the maximum depth reached.


Time Complexity: O(n)

Space Complexity: O(1)


---

4. Tywin's War Strategy

Platform: GeeksforGeeks

Approach:

Calculated the cost required to make each troop count divisible by k.

Selected the minimum costs needed to make at least ceil(n/2) troops lucky.


Time Complexity: O(n log n)

Space Complexity: O(n)

The problem asks for the minimum soldiers to add so that at least half of the troops have counts divisible by k. 


---

🧠 Key Learnings

Frequency arrays can efficiently solve substring problems.

Expand Around Center is a simple and powerful palindrome technique.

Parentheses depth can be tracked without actually using a stack.

Greedy selection can minimize the cost when each element has an independent cost.
