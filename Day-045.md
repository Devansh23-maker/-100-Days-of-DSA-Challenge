🗄️ SQL Practice
7. Second Highest Salary

Platform: LeetCode — LC 176

Concepts: DISTINCT, ORDER BY, LIMIT

SELECT (
    SELECT DISTINCT salary
    FROM Employee
    ORDER BY salary DESC
    LIMIT 1 OFFSET 1
) AS SecondHighestSalary;

Key Learning:
DISTINCT removes duplicate salaries, while OFFSET 1 skips the highest salary.
