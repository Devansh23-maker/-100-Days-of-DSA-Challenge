✅ Problems Solved

1. Minimum Number of Days to Make m Bouquets

Platform: LeetCode (LC 1482)

Approach:

- Binary searched the minimum possible day.
- For each candidate day, checked whether it was possible to make at least m bouquets with k adjacent flowers.

Time Complexity: O(n log D) (D = maximum bloom day)

Space Complexity: O(1)

---

2. Capacity to Ship Packages Within D Days

Platform: LeetCode (LC 1011)

Approach:

- Binary searched the ship capacity.
- Simulated shipping packages for each capacity and verified if all packages could be shipped within D days.

Time Complexity: O(n log S) (S = sum of package weights)

Space Complexity: O(1)

---

🧠 Key Learnings

- Binary Search on Answer works when the feasibility function is monotonic.
- The search range is determined by the minimum and maximum possible answers.
- Simulation functions validate whether a candidate answer satisfies the problem constraints.
- This pattern is one of the most frequently asked in coding interviews.
