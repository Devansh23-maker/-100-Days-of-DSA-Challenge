✅ Problems Solved
1. Longest Substring Without Repeating Characters

Platform: LeetCode (LC 3)

Approach:

Used a sliding window with a HashSet/HashMap.
Expanded the window while characters were unique and moved the left pointer when a duplicate appeared.

Time Complexity: O(n)
Space Complexity: O(n)

2. Find All Anagrams in a String

Platform: LeetCode (LC 438)

Approach:

Used a fixed-size sliding window.
Maintained character frequencies and compared them with the pattern.

Time Complexity: O(n)
Space Complexity: O(1)

3. Reverse Words in a String

Platform: LeetCode (LC 151)

Approach:

Removed unnecessary spaces.
Reversed the order of words.

Time Complexity: O(n)
Space Complexity: O(n)

4. Isomorphic Strings

Platform: LeetCode (LC 205)

Approach:

Used two HashMaps to maintain a one-to-one mapping between characters of both strings.

Time Complexity: O(n)
Space Complexity: O(n)

🧠 Key Learnings
Sliding Window is extremely useful for substring problems.
Hashing allows fast character lookup and frequency tracking.
Two-way mapping is required when a problem asks whether two strings follow the same pattern.
Always check edge cases involving spaces, duplicate characters, and empty strings.
