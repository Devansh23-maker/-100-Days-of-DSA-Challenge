✅ Problems Solved
1. Palindrome Linked List

Platform: LeetCode — LC 234

Approach:

Find the middle using slow and fast pointers.
Reverse the second half.
Compare both halves.

Time Complexity: O(n)
Space Complexity: O(1)

2. Odd Even Linked List

Platform: LeetCode — LC 328

Approach:

Maintain separate pointers for odd and even positioned nodes.
Connect the odd list with the even list at the end.

Time Complexity: O(n)
Space Complexity: O(1)

3. Delete the Middle Node of a Linked List

Platform: LeetCode — LC 2095

Approach:

Use slow and fast pointers to locate the middle node.
Keep track of the node before slow.
Remove the middle node by changing the previous node's next.

Time Complexity: O(n)
Space Complexity: O(1)

🧠 Key Learnings
Fast & Slow pointers can solve multiple Linked List problems.
Reversing part of a Linked List is a very important technique.
Many Linked List problems can be solved in-place with O(1) extra space.
Don't just memorize code—understand how changing next pointers changes the structure.
