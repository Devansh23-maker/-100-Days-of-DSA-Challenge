✅ Problems Solved
1. Reverse a Doubly Linked List

Platform: GeeksforGeeks

Approach:

Traverse through the DLL.
Swap the prev and next pointers of every node.
Update the head to the new first node.

Time Complexity: O(n)
Space Complexity: O(1)

2. Delete Head of a Doubly Linked List

Platform: GeeksforGeeks

Approach:

Move head to head.next.
Set the new head's prev to None.

Time Complexity: O(1)
Space Complexity: O(1)

3. Delete Node at the Last Index

Platform: GeeksforGeeks

Approach:

Traverse to the last node.
Move the previous node's next to None.
Update the tail if one is maintained.

Time Complexity: O(n)
Space Complexity: O(1)

🗄️ SQL Practice
4. Combine Two Tables

Platform: LeetCode — LC 175

Concept: LEFT JOIN

Goal: Combine information from two related tables using a common column.

Key SQL concept learned:

SELECT *
FROM Person p
LEFT JOIN Address a
ON p.personId = a.personId;

Key Learning:
LEFT JOIN keeps all records from the left table, even when there is no matching record in the right table.

🧠 Key Learnings
In a DLL, deleting a node requires updating both prev and next when applicable.
Reversing a DLL is essentially swapping the two pointers for every node.
LEFT JOIN is one of the most important SQL concepts for interviews.
Keep your DSA + SQL practice running together—it will help both your placement preparation and data/ML roadmap.
